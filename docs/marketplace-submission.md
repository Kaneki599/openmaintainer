# GitHub Marketplace submission

OpenMaintainer is ready for Marketplace publication as a single, public Action
repository with one root `action.yml`, a bundled entry point, stable releases,
and Marketplace branding.

## Final owner step in GitHub

GitHub requires the repository owner to complete this in the web interface:

1. Open [`action.yml`](../action.yml) in the repository and select **Draft a release** from the Marketplace banner.
2. Accept the GitHub Marketplace Developer Agreement if prompted. GitHub may require two-factor authentication.
3. Select **Publish this Action to the GitHub Marketplace**.
4. Choose **Security** as the primary category. Choose **Code quality** as a secondary category if it is available.
5. Select the existing `v0.1.2` release and publish it.

The release should not claim certifications, users, or security coverage that
the project has not earned. The Action is read-only and reports only the rules
documented in the README.
